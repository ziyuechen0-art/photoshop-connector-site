开始使用

安装帮助

  1. 从 Chrome Web Store 安装“发送到 Photoshop”。
  2. 下载 [Photoshop Connector](./downloads/Photoshop-Connector-Setup.exe)（Windows，Version 1.0.1）。
  3. 运行安装器并完成安装。
  4. 返回扩展 Welcome/状态页面，点击“重新检测”。
  5. 启动 Adobe Photoshop。
  6. 打开或创建一个 PSD 文档。
  7. 在网页图片上右键，选择“发送到 Photoshop”。

系统要求

  • Windows
  • Google Chrome
  • Adobe Photoshop
  • 导入前需打开一个 Photoshop 文档

你不需要做什么

不需要手动配置 Registry，不需要运行后台 HTTP 服务。Connector 由 Chrome 按需启动，扩展不会自动下载或运行安装器。

Connector 正式下载地址已在本页提供：./downloads/Photoshop-Connector-Setup.exe
