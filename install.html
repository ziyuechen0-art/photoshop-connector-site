开始使用

安装帮助

Extension 0.5.0 推荐 Photoshop Connector 1.0.2。1.0.1 核心发送功能可能可用；1.0.2 提供正确的 Photoshop 与当前文档状态检测。
  1. 从 Chrome Web Store 安装“发送到 Photoshop”。
  2. 下载 Photoshop Connector（Windows，Version 1.0.2）。
  3. 运行安装器并完成安装。已安装 1.0.1 时直接运行新安装器升级，无需先卸载。
  4. 返回扩展状态页并刷新。
  5. 启动 Adobe Photoshop。
  6. 打开或创建一个 PSD 文档。
  7. 在网页图片上右键，选择“发送到 Photoshop”。
  8. 如 Chrome 请求当前图片实际来源权限，可选择允许或拒绝。

登录保护图片

登录保护图片只在用户主动发送时尝试读取。请确保当前已登录原网站，并且对该图片具有相应访问和使用权限。扩展不会读取 Cookie 值、密码、Authorization 或 token。

系统要求

  • Windows
  • Google Chrome
  • Adobe Photoshop
  • 导入前需打开一个 Photoshop 文档

你不需要做什么

不需要手动配置 Registry。安装器会安装 Connector 并注册 Chrome Native Messaging Host；扩展不会自动下载或运行安装器。

Connector 正式下载地址：./downloads/Photoshop-Connector-Setup.exe
