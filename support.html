常见问题

为什么需要 Connector？

Chrome 扩展不能直接调用 Photoshop COM/JSX，Connector 是本机 Native Messaging 桥。

图片会上传服务器吗？

不会上传到开发者服务器。图片只在浏览器、本机 Connector 和本机 Photoshop 之间处理。

为什么第一次发送需要授权？

扩展按用户当前选择的图片来源请求可选权限，不在安装时获得全站访问权。

支持什么格式？

PNG、JPEG、WebP、GIF。SVG 暂不支持。

是否支持 Edge？

Chrome 正式版已配置。Edge 正式 Extension ID 尚未取得，当前不注册 Edge Native Host。

是否为 Adobe 官方产品？

不是。本产品是独立第三方工具。

故障排查

CONNECTOR_NOT_AVAILABLE

问题：未检测到 Connector。

原因：未安装、已卸载或 Chrome 无法启动 Host。

解决：安装/重新安装 Connector，点击“重新检测”。

PHOTOSHOP_NOT_RUNNING

问题：Photoshop 尚未运行。

解决：启动 Photoshop 后重新检测。

NO_ACTIVE_DOCUMENT

问题：Photoshop 已运行但没有文档。

解决：打开或创建 PSD 文档后重试。

HOST_PERMISSION_DENIED

问题：图片来源权限未批准。

解决：批准 Chrome 的来源权限后重试。

INVALID_IMAGE / UNSUPPORTED_IMAGE_FORMAT

问题：图片损坏、响应不是图片或格式不支持。

解决：选择有效 PNG、JPEG、WebP 或 GIF。

IMAGE_TOO_LARGE

问题：超过大小、尺寸或像素限制。

解决：使用更小图片。

PHOTOSHOP_IMPORT_FAILED

问题：图片读取成功但未加入 PSD。

解决：关闭 Photoshop 阻塞对话框，确认文档可编辑后重试。

卸载

Chrome → Extensions → Remove。Connector：Windows 设置 → 应用 → 已安装的应用 → Photoshop Connector → 卸载。卸载不会删除 PSD、Photoshop 设置或用户图片。
